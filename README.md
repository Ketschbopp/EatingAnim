# EatingAnim — Lightweight Pawn Animations (RimWorld 1.7)

Quick, render-only animations for pawns. Requires [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077).

| Category | What you see |
|---|---|
| Eating | **At a table:** pawn leans in, spoon/fork carries a morsel of the *actual food* to the mouth, then chews. **Without a table:** hunched posture, the *actual food item* is lifted to the mouth. **Animals:** head-down grazing bob. |
| Cooking | Frying pan (meals) or pot (everything else). The bill's *real ingredients* are tossed in and cook down while the *real product* (e.g. a lavish meal) forms as work progresses. Stirring, pan tosses, steam. |
| Butchering | Cleaver chops; chunks of the carcass's *own meat* fly on impact. |
| Manufacturing / crafting | Hammering (sparks at smithies/smelters), sewing, chisel + mallet for sculptures, a chemistry lab routine for drugs/medicine (flask poured from the test-tube rack into a fizzing, colour-changing beaker, then swirled) — the *real product* takes shape on the bench. |
| Work | Construction (hammer + dust), deconstruction (saw), mining (pickaxe + dust), sowing (trowel), harvesting (sickle), cleaning (broom), research (quill on paper). Tending and surgery are left vanilla. Modded jobs are picked up through the skill their work toil uses. |
| Games | Board games: pieces moved across the board. Poker: card fan + dealing. Dexterity games: wind-up and throw (horseshoe in hand for horseshoes). |
| Reading | Pages flip over the *real book / newspaper / document* being read — including modded ones that use the Reading joy kind. |
| Apparel / equipment | The *real garment* comes down over the pawn while they wiggle into it (and back up when removing). Equipping does a hop and a twirl of the *real weapon*. |

All animations work for every facing (north, east, south, west): lean, nods, tool angles, mirroring and draw layering are resolved per direction.

## Settings
Every category can be turned off, plus: master switch, animals on/off, props on/off, hide props when zoomed out, intensity and speed sliders.

## Other options
- **Disable shield belts** (off by default): worn shield belts block nothing, show no bubble, no longer prevent the wearer from shooting, and aren't favoured when pawns choose apparel. Shields built into creatures (e.g. mechanoids) are unaffected.

## Performance
- **No tick work.** Nothing is added to the simulation, so TPS is unaffected. (The only non-render hook records the tick a weapon was equipped.)
- **Render path only, on-screen pawns only.** Patches are postfixes on vanilla pawn drawing; off-screen pawns are never touched.
- **Stateless and allocation-free.** The animation is derived each frame from the pawn's current job via array lookups built once at startup (job → mode, recipe → animation, skill → animation). No per-pawn storage, no LINQ, no strings, no reflection at runtime.
- Body/head offsets are thread-safe and run inside vanilla's parallel pre-draw.
- Props are a few textured quads per animating pawn, skipped when zoomed out to cached rendering.

## Building
```
cd Source/EatingAnim
dotnet build -c Release
```
Builds against `Krafs.Rimworld.Ref` (1.7) and `Lib.Harmony` reference assemblies into `1.7/Assemblies/`. Requires the .NET 10 SDK.

Tool textures are generated by `Tools/gen_textures.py` (Pillow).
